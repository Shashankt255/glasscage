# Code of Conduct

This project adopts the Contributor Covenant v2.1. We are committed to a harassment-free
experience for everyone. Unacceptable behavior includes harassment, discrimination, and
personal attacks.

Given GLASSCAGE is a security tool: do not use project spaces to solicit, share, or
coordinate attacks against systems you are not authorized to test.

Report violations to conduct@glasscage.example (placeholder). Maintainers will review
and respond, and may remove contributions or contributors who violate this policy.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
